Update competitor prices: one-time setup

1. Show your bookmarks bar in Chrome (Ctrl+Shift+B, or Cmd+Shift+B on a Mac).
2. Drag this button onto the bookmarks bar: Load to HC Pricing
3. Each day: click Update competitor prices at the top of this page. Lighthouse opens in a new tab (log in if asked). Click the Load to HC Pricing bookmark there. It takes about a minute, then the box there says "done", and this page updates by itself.
The code it uses works once, within 15 minutes. Lighthouse updates competitor prices about once a day, so once a day is enough.
